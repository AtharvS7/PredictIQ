## 1. Objectives & Compliance
- **Monetary Cost Distribution:** Aligned parametric cost calculations with empirical effort intervals ($p10, p50, p90$) and user-specified hourly rates:
  $$\text{Cost}_{p} = \text{Effort}_{p} \times \text{Rate}$$
- **Zero Fabricated Multipliers:** Eliminated arbitrary multipliers from risk scoring into effort estimation. Risk analysis runs downstream as a diagnostic tool and does not artificially distort effort predictions.
- **Contract Schema Conformance:** Added `calculate_cost_v2` in `backend/app/services/cost_calculator.py` emitting contract-conforming cost quantiles (`p10`, `p50`, `p90`, `currency`, `rate`).
- **Risk Analyzer Integrity:** Project risks are transparently categorized into Low, Medium, High, and Critical severities with specific actionable mitigation descriptions.

## 2. Implementation Details

### `backend/app/services/cost_calculator.py`
- Implemented `calculate_cost_v2(effort_hours, hourly_rate, currency)` returning:
  ```json
  {
    "p10": 136342.34,
    "p50": 178200.00,
    "p90": 232745.12,
    "currency": "USD",
    "rate": 75.0
  }
  ```
- Guaranteed non-crossing property: $\text{Cost}_{p10} \le \text{Cost}_{p50} \le \text{Cost}_{p90}$.

### `backend/app/services/risk_analyzer.py`
- Bounded 0-100 risk score based on architectural characteristics (technology breadth, timeline compression, scope definition).
- Generates up to 5 highest-severity `RiskItem` objects for UI visibility.
