## 1. Executive Summary

Checkpoint **S05** establishes empirical validation of the PredictIQ NLP feature extraction engine (`backend.app.services.nlp_extractor`) against authentic, uncurated real-world software requirements specifications, replacing prior ungrounded assumptions with reproducible scientific standards:

1. **Synthetic Regression Demarcation:** The 36 agent-written documents previously located in `backend/tests/fixtures/srs/` were relocated to `backend/tests/fixtures/srs_synthetic/` and documented with explicit caveats that the 0.00% MdAPE achieved on that synthetic corpus reflects template alignment by construction and **does NOT represent real-world extraction accuracy**.
2. **Real-World Requirements Corpus Collection:** Curated 18 authentic public requirements specifications totaling 95,299 words (~272 pages) into `backend/tests/fixtures/srs_real/` from the canonical **PURE (PUblic REquirements) dataset** (Zenodo Record 7118517, CC-BY-4.0, IEEE RE 2017) and public domain/open-source projects.
3. **Empirical Engine Validation:**
   - **Zero Crashes:** 18/18 real specifications parsed with zero unhandled exceptions.
   - **Strict Finite Monotonic Outputs:** All numeric outputs ($S_{\text{FP}}$, confidence, $P_{10}, P_{50}, P_{90}$) are strictly finite, positive, and satisfy quantile non-crossing ($0 < P_{10} \le P_{50} \le P_{90}$).
   - **High Performance Scaling:** Achieved median latency of **0.143s**, p90 latency of **0.553s**, and p95 latency of **0.618s** (exceeding the $\le 3.0\text{s}$ gate by a 4.8x margin). The largest specification (PEPPOL, 24,088 words / ~68.8 pages) parsed in **0.844s**.
4. **Human Ground-Truth Labeling Program:** Created `docs/data/NLP_LABELING_TASK.md` and CSV template `docs/data/nlp_real_labeling_template.csv` covering 15 target real specifications. Built the automated evaluation harness (`backend/ml/eval/run_real_srs_eval.py`) that reads human annotations when present to calculate genuine empirical MdAPE/MAPE without fabricating ground truth.
5. **Configurable Sizing Assumptions:** Replaced hardcoded sizing constants with `FunctionalSizeSizingConfig`, explicitly tagging derived functional sizes with `is_assumption = True`, documented assumption rationale, and wide uncertainty intervals.
6. **Adversarial Robustness & Edge Cases:** Built 19 automated tests in `backend/tests/test_nlp_robustness.py` covering catastrophic regex backtracking (ReDoS defense), 50-page scaling, corrupted PDF/DOCX binaries, and multi-encoding variations (UTF-8 BOM, UTF-16 LE/BE, Latin-1, CP1252, CJK/emojis).

## 5. Configurable Sizing Assumption Framework

Prior to S05, `nlp_extractor.py` hardcoded:
$$\text{derived\_fp} = \max(10.0, \text{features} \times 8.0 + \text{integrations} \times 5.0)$$

This hardcoded rule was replaced by `FunctionalSizeSizingConfig`:

```python
@dataclass(frozen=True)
class FunctionalSizeSizingConfig:
    fp_per_story: float = 8.0
    fp_per_story_p10: float = 4.0
    fp_per_story_p90: float = 14.0
    fp_per_integration: float = 5.0
    fp_per_integration_p10: float = 2.0
    fp_per_integration_p90: float = 10.0
    uncertainty_p10_ratio: float = 0.85
    uncertainty_p90_ratio: float = 1.15
    min_size_fp: float = 10.0
    default_nominal_fp: float = 90.0
    is_assumption: bool = True
    assumption_rationale: str = (
        "Heuristic conversion assumption: nominal 8.0 FP/user story (uncertainty range [4.0, 14.0]) and "
        "5.0 FP/integration touchpoint (uncertainty range [2.0, 10.0]) derived from agile sizing guidelines; "
        "exhibits wide empirical variance."
    )
```

The output payload explicitly annotates that sizing is a heuristic assumption and provides wide uncertainty intervals:
```json
{
  "size_fp": {
    "value": 116.0,
    "confidence": 0.85,
    "uncertainty": {"p10": 98.6, "p50": 116.0, "p90": 133.4},
    "source": "nlp",
    "is_assumption": true,
    "assumption_parameters": {
      "fp_per_story_nominal": 8.0,
      "fp_per_story_range": [4.0, 14.0],
      "fp_per_integration_nominal": 5.0,
      "fp_per_integration_range": [2.0, 10.0],
      "wide_uncertainty_interval": [58.0, 208.0],
      "rationale": "Heuristic conversion assumption..."
    }
  }
}
```
