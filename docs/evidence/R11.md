## 3. CLI Features & Execution Options

`scripts/release_gate.py` provides flexible execution controls for local development, CI workflows, and pre-commit checks:

- `--skip-slow`: Skips long-running suites (Step 3 Backend Pytest, Step 6 Frontend Vitest, Step 7 Production Build), completing fast linting, typechecks, security audits, and branch protection checks in under 40 seconds.
- `--backend-only`: Executes only backend and repository audit steps (Steps 1, 2, 3, 4, 8, 9).
- `--frontend-only`: Executes only frontend and repository audit steps (Steps 5, 6, 7, 8, 9).
- `--fail-fast`: Immediately aborts execution upon encountering the first failed check, presenting stderr diagnostics immediately without waiting for remaining suites.
- `--allow-uncommitted` (alias `--dirty`): Allows local runs with uncommitted working tree changes, emitting a `WARN` status for Step 8 instead of a hard `FAIL`. Releases require clean trees by default.
- `--json`: Emits structured JSON output with timestamps, durations, and per-step exit codes for CI artifact collection.

## 4. CI Workflow Hardening (`.github/workflows/ci.yml`)

The GitHub Actions CI workflow was hardened to guarantee complete local and remote parity:

1. **Job 0 (`release-gate`):** Added a dedicated unified gate validation job executing `python scripts/release_gate.py --skip-slow` on both push and pull request events.
2. **Backend Lint Parity (`lint-backend`):**
   - Synchronized Ruff flags: `ruff check backend/app backend/ml --select E,W,F,I --ignore E501,E402`.
   - Synchronized Mypy execution: `cd backend && mypy app/` using `backend/mypy.ini`.
3. **Frontend Lint & Test Parity (`lint-frontend`):**
   - Synchronized typecheck: `npm --prefix frontend run typecheck`.
   - Synchronized Vitest pool: `npx --prefix frontend vitest run --root frontend --pool=forks`.
4. **Security & Scripts Parity (`security-scan`):**
   - Upgraded script regression checks to `pytest scripts/tests -q`.
5. **Docker Build Dependencies (`docker-build-check`):**
   - Gate dependencies now require `release-gate` along with `test-backend`, `build-frontend`, `security-scan`, and `authenticated-e2e`.
