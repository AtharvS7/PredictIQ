# Validation Evidence: Natural Language Processing and Requirements Sizing Robustness

Status: Approved | Applies to: 2.0.0-rc.3 | Verified against commit: f6192a9172364dbb976f87df105a5857a1cafc4f | Date: 2026-11-15

---

## 1. Scope of Implementation
- **Multi-Signal Requirements Sizing:** Implemented comprehensive multi-signal extraction across 8 structured indicators in `backend/app/services/nlp_extractor.py`:
  1. User stories (`As a <role>, I want <goal>, so that <benefit>`)
  2. Numbered and tagged requirements (`REQ-`, `FR-`, `SR-`, numbered lists)
  3. Normative modal statements (`shall`, `must`, `will`, `should`)
  4. Structured use case blocks (`Use Case:`, `Actor:`)
  5. Module and architectural components (`Module:`, `Component:`)
  6. Data and functional specification tables (Markdown tables)
  7. Acceptance criteria blocks (`Scenario:`, `Given/When/Then`)
  8. External integration specifications (`REST API`, `Webhook`, `SDK`)
- **Deduplication and Hierarchy:** Statement fingerprinting prevents overlapping patterns from double-counting. Section-based scoping prioritizes functional requirement sections when explicit headers exist, falling back gracefully to document-wide multi-signal synthesis.
- **Plausibility Detection:** Added sizing ratio validation for lengthy documents exceeding 3,000 words with sparse functional requirement markers, providing informative confidence guidance to users.
- **Parser Robustness:** Updated `backend/app/services/document_parser.py` and `backend/app/api/v1/documents.py` to support Markdown, plain text, DOCX, and PDF formats with standardized user messaging on unparseable or empty uploads.
- **Comprehensive Test Suite:** Developed 64-fixture test corpus spanning synthetic requirements, real-world public specifications (PURE corpus), and 10 edge case fixtures in `backend/tests/fixtures/srs_robustness/`.

## 2. Verification Summary
- **Zero Exception Invariant:** The 64-document corpus processed through the extraction pipeline with zero unhandled exceptions, zero non-finite outputs, and zero server crashes.
- **Performance Profiling:** Processing latency across the entire corpus achieved p95 of 0.23 seconds (target: < 3.0 seconds). A synthetic 50-page document processed in 0.38 seconds.
- **ReDoS Safety:** Regex patterns verified safe against exponential backtracking with timeout assertions.
- **Quality Benchmarks:** All 5 synthetic gold benchmark quality gates passed (MdAPE <= 20%, F1 >= 0.85, Recall >= 90%, MAE <= 1.0).
