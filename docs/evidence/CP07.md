## 1. Objectives

- Implement the evaluation harness in package `backend/ml/eval/` strictly conforming to `docs/contracts/evaluation_protocol.md` and `docs/contracts/ml_contract.md`.
- Implement `LeaveOneSourceOutSplitter`:
  - Partitions `backend/ml/data/projects_v2.csv` (915 rows) into 6 disjoint folds corresponding to the 6 empirical sources (`china`: 499, `kitchenham`: 145, `att_aptness`: 104, `desharnais`: 81, `maxwell`: 62, `albrecht`: 24).
  - Enforces cryptographic assertions that training and test partitions share zero project IDs.
- Implement `RepeatedGroupedKFoldSplitter` for repeated group-preserving cross-validation.
- Implement frozen metrics in `backend/ml/eval/metrics.py`:
  - $R^2$, RMSE, MAE
  - MdMRE and MdAPE (Primary Metric: $\text{median}(|\hat{y} - y| / y) \times 100\%$)
  - PRED(25), PRED(30), PRED(50)
  - RMSLE, Log-space bias, MMRE, Standardized Accuracy (SA)
  - Macro-averaging aggregation across folds
- Implement 5 baseline estimators in `backend/ml/eval/baselines.py`:
  1. `MedianDummyPredictor`: constant median effort of training fold.
  2. `MedianProductivityPredictor`: median productivity multiplier $P = \text{median}(y / S)$ applied to size.
  3. `AlbrechtNominalPredictor` (COCOMO / Power Law): empirical power-law $E = a \cdot S^b$ fitted via OLS in log space.
  4. `LogLinearBaseline`: OLS on $\log(S)$ and optional $\log(\text{duration})$.
  5. `HuberPowerLawBaseline`: Huber robust regression on log-log transform.
- Implement CLI evaluation script `backend/ml/eval/run_eval.py` that executes the full Leave-One-Source-Out evaluation of all baselines and serializes results to `docs/evidence/CP07_baseline_results.json`.
- Implement comprehensive automated test suite `backend/tests/test_eval_harness.py` verifying split disjointness, hand-calculated metric accuracy, and baseline estimator properties.

## 4. Key Findings

1. **Establishment of Track 1 Performance Floor:**
   - The best Track 1 baseline model (`LogLinearBaseline` / `AlbrechtNominalPredictor`) achieves a macro-average MdAPE of **56.0%** and **56.1%**, with Standardized Accuracy of **22.5%** and PRED(25) of **20.5%**.
   - Under the frozen CP10 Decision Rule (`docs/contracts/evaluation_protocol.md`), any Track 2 challenger model must improve upon this MdAPE by $\ge 5\%$ relative ($\text{MdAPE}_{\text{Challenger}} \le 53.2\%$), maintain $p < 0.05$ on Wilcoxon signed-rank test, avoid $> 10\%$ degradation on any single source fold, and provide conformal interval coverage within nominal $\pm 5\%$.
2. **Transferability Disparities:**
   - Performance varies significantly across holdout domains: `maxwell` (aerospace/defense) achieves 34.5% MdAPE under `LogLinearBaseline`, while `albrecht` (1980s MIS banking projects) exhibits 72.2% MdAPE.
   - This empirically confirms the necessity of Leave-One-Source-Out validation over random split CV, which would leak organizational productivity baselines and artificially inflate performance.
3. **Productivity Multiplier Inadequacy:**
   - The naive constant productivity baseline (`MedianProductivityPredictor`) yields negative $R^2$ (-0.637) on China data due to nonlinear diseconomies of scale. Empirical power-law models ($E = a \cdot S^b$) properly capture sub-linear/super-linear scale effects.
