## 1. Overview and Architecture

Checkpoint H04 establishes independent mathematical verification of all estimation and financial formulas across the full project scope gradient (1 to 4,500 Function Points):

1. **Independent Mathematical Recomputation (`backend/tests/test_calc_verification.py`):**
   - Grounded directly on pure JSON parsing of `backend/ml/artifacts/production_v2/model_params.json` without depending on ML inference libraries or runtime classes.
   - Validated point estimate formula:
     $$\text{Effort}_{p50} = a \cdot \text{Size}^b$$
     with parameters $a = 24.24077404471689$ and $b = 0.8270266757672359$.
   - Validated scale-stratified empirical quantile multipliers across 3 scale partitions:
     - *Small (< 150 FP):* $q_{80} = 1.148105$, $q_{50} = 0.607290$.
     - *Medium (150–750 FP):* $q_{80} = 0.956136$, $q_{50} = 0.599901$.
     - *Large (> 750 FP):* $q_{80} = 1.186439$, $q_{50} = 0.656491$.
   - Tested 48 distinct project functional sizes spanning the entire domain: 1, 2, 5, 10, 15, 20, 25, 30, 40, 50, 65, 80, 100, 120, 135, 145, 149, 150, 151, 160, 180, 200, 225, 250, 300, 350, 400, 450, 500, 550, 600, 650, 700, 749, 750, 751, 800, 900, 1000, 1200, 1500, 1800, 2000, 2500, 3000, 3500, 4000, 4500 FP.
   - Verified that every output quantile matches independent pure-math calculation within floating-point tolerance.
   - Enforced non-crossing quantile invariant across all test sizes:
     $$1.0 \le P_{10} \le P_{25} \le P_{50} \le P_{75} \le P_{90}$$
   - Confirmed strict monotonicity: each step increase in project functional size produces a strictly positive increase in estimated effort hours.

2. **Cost Calculation Parity & Multi-Currency Parity:**
   - Enforced strict financial relationship $\text{Cost} = \text{Effort} \times \text{Rate}$ rounded to 2 decimal places across multiple blended rates ($25 to $250/hr).
   - Validated currency conversion calculations for USD, EUR, and INR.
   - Confirmed ReportLab PDF report generation integrity, valid binary `%PDF` structure, and branding alignment ("PredictIQ").

3. **Artifact Immutability:**
   - Production model parameter artifact `model_params.json`, manifest `manifest.json`, empirical dataset `projects_v2.csv`, and evaluation metrics remain 100% frozen and untouched.
   - Cryptographic verification via `load_production_model()` confirms hash alignment.
