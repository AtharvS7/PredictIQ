## 1. Objectives & Mathematical Formulations

Checkpoint CP08 implements the Track 1 effort estimation models for PredictIQ v2 in package `backend/ml/track1/`. All models are transparent, interpretable, strictly monotonic, and adhere without exception to `docs/contracts/ml_contract.md`.

### 1.1 Model 1: `MonotonePowerLaw`

Standard empirical power law relating Functional Size $S$ (Function Points) to Effort $E$ (person-hours):
$$E = a \cdot S^b$$
In logarithmic space:
$$\ln(E) = \beta_0 + b \cdot \ln(S), \quad a = \exp(\beta_0)$$

- **Monotonicity Invariant:** Size elasticity $b > 0$ is strictly enforced via bounded Huber robust loss optimization:
  $$\min_{\beta_0 \in \mathbb{R}, \, b \ge b_{\min}} \sum_{i=1}^N H_\delta\left(\ln(y_i) - (\beta_0 + b \ln(S_i))\right)$$
  with $b_{\min} = 10^{-4}$ and $\delta = 1.35$.
- **Analytical Derivative:**
  $$\frac{\partial E}{\partial S} = a \cdot b \cdot S^{b - 1} > 0 \quad \forall S > 0$$
- **Fitted Full-Dataset Parameters:** $a = 20.6104$, $b = 0.8520$ ($\beta_0 = 3.0258$).

---

### 1.2 Model 2: `MultivariateMonotoneModel`

Multivariate power law incorporating Functional Size $S$ and Planned Target Duration $D$ (months):
$$E = a \cdot S^b \cdot D^c$$
In logarithmic space:
$$\ln(E) = \beta_0 + b \cdot \ln(S) + c \cdot \ln(D)$$

- **Physical Constraints:**
  - Size elasticity $b > 0$ strictly enforced ($b \ge b_{\min}$).
  - Duration elasticity $c$ bounded to physically realistic bounds: $c \in [0.0, 1.2]$.
- **Zero Synthetic Imputation:**
  - Evaluated on datasets where duration is partially observed (e.g., China and Maxwell have duration; Kitchenham, AT&T, Desharnais, and Albrecht do not).
  - When duration $D$ is missing ($D = \text{null}$ or non-positive), the model evaluates the marginal base power law:
    $$E = a_{\text{base}} \cdot S^{b_{\text{base}}}$$
  - No synthetic or fabricated duration values are ever imputed into feature matrices, strictly preserving the ML contract.
- **Fitted Full-Dataset Parameters:**
  - Multivariate: $a = 24.2428$, $b = 0.5871$, $c = 0.5972$
  - Base Marginal: $a_{\text{base}} = 20.6104$, $b_{\text{base}} = 0.8520$

### 1.3 Model 3: `SegmentedMonotoneModel`

Size-bucketed power law partitioning the functional size domain into three empirical buckets:
- **Small:** $S < 150\text{ FP}$
- **Medium:** $150 \le S \le 750\text{ FP}$
- **Large:** $S > 750\text{ FP}$

To eliminate abrupt jump discontinuities and derivative cliffs between buckets, the model employs numerically stable softplus smoothing in log-space:
$$\ln(E(S)) = \beta_0 + b_1 \phi_1(x) + b_2 \phi_2(x) + b_3 \phi_3(x)$$
where:
$$x = \ln(S), \quad k_1 = \ln(150) \approx 5.0106, \quad k_2 = \ln(750) \approx 6.6201$$
$$h(z; \tau) = \tau \ln\left(1 + e^{z/\tau}\right) \quad (\tau = 0.25)$$
$$\phi_1(x) = x - h(x - k_1; \tau)$$
$$\phi_2(x) = h(x - k_1; \tau) - h(x - k_2; \tau)$$
$$\phi_3(x) = h(x - k_2; \tau)$$

- **Monotonicity & Smoothness Proof:**
  The derivative of $\ln(E)$ with respect to $x$ is:
  $$f'(x) = b_1 (1 - \sigma_1(x)) + b_2 (\sigma_1(x) - \sigma_2(x)) + b_3 \sigma_2(x)$$
  where $\sigma_1(x) = \sigma((x - k_1)/\tau)$ and $\sigma_2(x) = \sigma((x - k_2)/\tau)$.
  Because $k_1 < k_2$, we have $\sigma_1(x) \ge \sigma_2(x)$ for all $x \in \mathbb{R}$.
  Therefore, the weights $(1 - \sigma_1)$, $(\sigma_1 - \sigma_2)$, and $\sigma_2$ are strictly non-negative and sum identically to $1$.
  Since $b_1, b_2, b_3 \ge b_{\min} > 0$:
  $$f'(x) \ge \min(b_1, b_2, b_3) \ge b_{\min} > 0 \quad \forall x \in \mathbb{R}$$
  $$\implies \frac{\partial E}{\partial S} = \frac{E(S)}{S} \cdot f'(\ln(S)) > 0 \quad \forall S > 0$$
  This mathematically guarantees strict monotonicity and $C^\infty$ smoothness everywhere.
- **Fitted Full-Dataset Parameters:**
  - $\beta_0 = 3.4196$
  - $b_1 (\text{small } < 150\text{ FP}) = 0.7611$
  - $b_2 (\text{medium } 150\text{--}750\text{ FP}) = 0.9284$
  - $b_3 (\text{large } > 750\text{ FP}) = 0.7874$

### 1.4 ML Contract Enforcement (`docs/contracts/ml_contract.md`)

- **Banned Features:** The input validator rejects any DataFrame containing legacy complexity factors (`T01`--`T15`), legacy unadjusted metrics (`Transactions`, `Entities`, `PointsNonAdjust`, `Adjustment`), team/manager experience (`TeamExp`, `ManagerExp`), or downstream outputs (`risk_score`).
- **Bounded Predictions:** Predicted effort is strictly guaranteed positive and finite, clamped from below to $\ge 1.0$ person-hour.
- **Scikit-Learn Compatibility:** All models inherit from `BaseEstimator` and `RegressorMixin`, supporting `fit(X, y)` and `predict(X)`.

## 4. Key Performance Insights

1. **`MultivariateMonotoneModel` is the top-performing model across all metrics:**
   - **MdAPE:** Drops to **53.9%** (outperforming all CP07 baselines, including `LogLinearBaseline` at 56.0%).
   - **$R^2$:** Surges to **0.314**, representing a +34.8% relative gain over `AlbrechtNominalPredictor` (0.233) and +55.4% over `LogLinearBaseline` (0.202).
   - **Standardized Accuracy (SA):** Reaches **25.3%**, showing superior prediction gain over random median guessing.
   - **China Fold Breakthrough:** On the largest holdout source (`china`, 499 projects), MdAPE drops to **49.7%**, $R^2$ jumps to **0.490**, and MAE decreases from 2886 to **2242 hours**.
2. **Zero-Imputation Robustness:**
   - On the 4 holdout sources lacking duration (`kitchenham`, `att_aptness`, `desharnais`, `albrecht`), `MultivariateMonotoneModel` evaluates the marginal size power-law without fabricating synthetic inputs, guaranteeing identical and stable transferability.
3. **`SegmentedMonotoneModel` High Precision:**
   - Achieves the highest single-feature PRED(25) score (**20.7%**) with guaranteed mathematical monotonicity ($\partial E / \partial S > 0$ everywhere).
