# Checkpoint R09 Evidence: NLP & Golden SRS Benchmark Suite

## 1. Executive Summary

- **Objective:** Establish an empirical, reproducible gold-standard Software Requirements Specification (SRS) benchmark suite across diverse software engineering domains to evaluate and guardrail the NLP feature extraction pipeline (`backend.app.services.nlp_extractor`).
- **Benchmark Corpus:** 36 verified, full-length Software Requirements Specification documents spanning 6 software engineering domains (6 documents per domain) with complexity tiers from minimal MVPs to mission-critical enterprise systems.
- **Ground Truth Grounding:** Every document is mapped to verified, authoritative ground-truth values in `backend/tests/fixtures/srs/annotations.json` detailing functional size ($S_{\text{FP}}^*$, range $[P_{10}^*, P_{90}^*]$), declared and detected technology stacks, external interface integrations, numbered functional requirements, team size, duration, and operational complexity.
- **Automated Harness:** Executed via `backend/ml/eval/run_r09_srs_eval.py` feeding documents into `extract_features_from_document` and dumping raw empirical metrics to `docs/evidence/r09_srs_results.json`.
- **Status:** **PASS — All Quality Gates Met or Exceeded.**
