## 3. Frozen Evaluation Protocol & CP10 Decision Rule
- **Contract Path:** `docs/contracts/evaluation_protocol.md`
- **FROZEN SHA-256 Anchor:**
  `b3fac93ff853f213dba8f0815dfea0f837dc5fa035fc7a8ba2b10c24fa8834e0`
- **Pre-Registered Protocol:**
  - Leave-One-Source-Out (LOSO) Cross-Validation and Repeated Grouped K-Fold
  - Metrics: MdAPE, MAE (hours), RMSLE, PRED25, PRED50, log-space bias, standardized accuracy, MMRE (flagged as misleading alone), per-source and size-bucket breakdowns, bootstrap 95% CIs, paired Wilcoxon test
  - Baselines: global median, median productivity, log-log OLS power law, Huber power law
- **CP10 Challenger Decision Rule:**
  - Track 2 flexible model beats Track 1 simple baseline iff:
    1. LOSO MdAPE improves $\ge 5\%$ relative,
    2. Paired Wilcoxon signed-rank $p < 0.05$,
    3. No single historical source degrades $> 10\%$ relative,
    4. Conformal interval coverage is not worse.
  - Single-shot execution rule enforced: no re-tuning or repeated runs allowed.
