Status: Approved | Applies to: 2.0.0-rc.3 | Date: 2026-11-15

## 1. Overview and Architecture

Checkpoint H01 establishes the single-command production launcher `python run.py` designed for executive demonstrations and local deployment without Docker dependencies:

1. **Preflight System Audit:**
   - Detects the designated Python 3.12 virtual environment (`.venv`).
   - Verifies required backend environment variables (`DATABASE_URL`, `FIREBASE_CREDENTIALS_PATH`, `APP_ENV`).
   - Verifies frontend environment configuration.
   - Validates Firebase service account credentials file and matches project ID with frontend configuration.
   - Tests cloud PostgreSQL reachability via TCP socket connection (with offline fallback notice if unreachable).

2. **ML Model Validation:**
   - Cryptographically verifies model parameter artifact `backend/ml/artifacts/production_v2/model_params.json` using canonical UTF-8 SHA-256 against `manifest.json`.
   - Computes mathematical baseline effort prediction for 50 FP (~616.1 hours).
   - Operates with zero untrusted pickle deserialization and zero training scripts.

3. **Dynamic Port Allocation & Conflict Avoidance:**
   - Backend scans ports 8010 through 8019 for the first free port (strictly rejecting port 8000).
   - Frontend scans ports 5173 through 5179 for the first free port.
   - CORS middleware automatically permits dev/preview ports 5173 through 5179 dynamically in non-production environments.

4. **Production Bundle Serving & Reverse Proxy:**
   - Automatically builds frontend bundle (`npm run build`) if `dist/` is missing or older than source files.
   - Serves production build using `vite preview` with reverse proxy forwarding `/api` requests to the dynamically allocated backend port.
   - Automatically opens default browser to `http://localhost:<frontend_port>` (satisfying Firebase Auth domain requirements).

5. **Lifecycle Management & Stale Process Cleanup:**
   - Tracks active child processes in `.agent/run.pid`.
   - Cleans up stale processes from interrupted runs before starting.
   - Handles `SIGINT` and `SIGTERM` gracefully, cleanly terminating process trees without orphaned listeners.
