# Checkpoint R07 Evidence: Challenger Models Re-evaluation under Frozen Protocol

## 1. Executive Summary
- **Protocol:** 6-fold Leave-One-Source-Out (LOSO) cross-validation on harmonized gold standard dataset `projects_v2.csv` ($N = 915$).
- **Held-out Sources:** `albrecht` (24), `att_aptness` (104), `china` (499), `desharnais` (77), `kitchenham` (145), `maxwell` (62).
- **Frozen Decision Criteria (Pre-registered in `docs/contracts/evaluation_protocol_rc2.md`):**
  1. $\text{Macro MdAPE}_{\text{challenger}} \le \text{Macro MdAPE}_{\text{incumbent}} \times 0.97$ ($\ge 3.0\%$ relative improvement).
  2. $\text{Macro PRED25}_{\text{challenger}} \ge \text{Macro PRED25}_{\text{incumbent}} - 1.0\%$ (non-inferiority).
  3. Strictly preserves positive monotonicity with respect to functional size ($\partial E / \partial S \ge 0$).
  4. Requires only observable, verified inputs without synthetic imputation or banned features.
- **Outcome:** **PASS — Incumbent Confirmed.**
  - Model B achieved $+0.29\%$ relative gain (below the $+3.0\%$ threshold).
  - Model D achieved $-2.72\%$ relative gain (worse than incumbent).
  - Track 2 MonotoneHistGradientBoosting achieved $-0.33\%$ relative gain (worse than incumbent).
  - Under the pre-registered frozen evaluation protocol, **Model A (MonotonePowerLaw)** remains the production estimator.

## 3. Analysis & Scientific Findings
1. **Model A Parsimony & Robustness:**
   Power-law regression ($\ln E = \alpha_0 + \beta \ln S$) with empirical calibration remains exceptionally robust across heterogeneous historical software datasets. In software effort estimation, unobserved team factors and organisational productivity vary widely between datasets; non-linear gradient boosted trees overfit within-source variance without generalising better to completely unseen out-of-domain sources.
2. **Model B Marginals:**
   Under true out-of-domain transfer (unseen organization/source), the random intercept has zero expectation ($\mathbb{E}[u_{\text{new}}] = 0$), collapsing predictions to the marginal fixed effect. While within-sample fit improves with random effects, the generalization gain on held-out sources is negligible ($+0.29\%$).
3. **Empirical Bayes Synergy:**
   While global challengers fail to beat Model A out-of-domain, once an organization provides actual completed project data ($k \ge 3$), the Empirical Bayes shrinkage developed in R05 provides massive gains ($+11.89\%$ at $k=3$, $+19.52\%$ at $k=10$), establishing a principled two-tier estimation architecture:
   - Tier 1: Global Model A with Conformal Uncertainty for zero-history organizations.
   - Tier 2: Empirical Bayes Shrunk Model for organizations with logged completed projects.
