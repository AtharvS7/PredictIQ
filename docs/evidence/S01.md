## 3. Canonical Bytes Hashing & Newline-Invariance Proof

In `backend/ml/artifacts/loader.py`:
- `compute_canonical_json_sha256(data)` parses the JSON object and computes the SHA-256 digest over canonical UTF-8 bytes:
  ```python
  canonical_bytes = json.dumps(
      obj,
      sort_keys=True,
      indent=2,
      ensure_ascii=False,
  ).encode("utf-8")
  return hashlib.sha256(canonical_bytes).hexdigest()
  ```
- Line endings on disk (`\r\n` on Windows vs `\n` on Linux) cannot alter the verified hash.

### Empirical Invariance Verification
```powershell
.\.venv\Scripts\python.exe -c "
from pathlib import Path
from backend.ml.artifacts.loader import compute_canonical_json_sha256

p = Path('backend/ml/artifacts/production_v2/model_params.json')
text = p.read_text(encoding='utf-8')

hash_lf = compute_canonical_json_sha256(text.replace('\r\n', '\n'))
hash_crlf = compute_canonical_json_sha256(text.replace('\r\n', '\n').replace('\n', '\r\n'))

print('LF Hash:  ', hash_lf)
print('CRLF Hash:', hash_crlf)
assert hash_lf == hash_crlf == '8066e9cf4c18f5fa45957bad9050cbab6effb68923a787f974640a463ede93d2'
print('VERIFICATION: EXACT MATCH')
```
