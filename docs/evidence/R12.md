## 3. Cryptographic Verification & Safe Deserialization
In `backend/ml/artifacts/loader.py`:
1. Cryptographic SHA-256 verification of `manifest.json` and `model_params.json` against manifest file hashes.
2. Production loader checks `model_params_file = dir_path / "model_params.json"`. When present, parameters are parsed with standard `json.load()` and assigned to clean estimator and calibrator structures.
3. Zero `pickle.load` invocations occur in the serving pipeline.
4. If `model_params.json` is missing or tampered, fail-closed runtime checks abort startup immediately.
