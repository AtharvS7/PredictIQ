## 1. Executive Summary

In Checkpoint S03, PredictIQ executed an exhaustive, empirical data acquisition and provenance investigation across all prominent open and published software engineering project estimation benchmark datasets. Rather than performing a superficial literature survey, real network downloads were executed against Zenodo, GitHub, OpenML, and academic repositories.

Every acquired and candidate source was evaluated against three non-negotiable data integrity principles:
1. **Zero Fabricated Rows:** Every row must represent an authentic completed software engineering project from audited source documentation.
2. **Zero Unrecorded Conversions:** Sizing metrics (IFPUG FP, COSMIC CFP, FiSMA FP, Object Points, KLOC, Web Objects, Changes) and effort metrics (Person-Hours, Person-Months, Financial Costs) must never be cross-converted using arbitrary heuristic multipliers or synthetic gearing factors.
3. **Primary Training Purity:** The core training dataset (`projects_v2.csv`, 915 projects) remains exclusively composed of valid IFPUG Function Points and verified person-hours. All candidate datasets with divergent sizing standards or person-month effort are segregated into documented secondary benchmark tracks.
