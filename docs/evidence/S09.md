4. **Documentation Specification Audit (`scripts/docs_audit.py`):**
   - Audits 124 markdown files in `docs/`: validates status headers, historical warning banners, zero banned hype words (`guaranteed`, `state-of-the-art`, `industry-grade`), internal anchor links, and active spec hygiene.
