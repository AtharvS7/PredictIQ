# Verification Report H09: UTF-8 Launch Hardening and Rate Limiter Isolation

Status: Approved | Applies to: 2.0.1 | Verified against commit: fbcb6e4 | Date: 2026-11-15

---

## 1. Executive Summary & Verification Overview

Verification Report H09 documents the resolution and full verification of environment encoding resilience across the PredictIQ single-command demonstration launcher (`python run.py`), application runtime services, and configuration templates:

1. **Launcher Environment Hardening:** `run.py` now explicitly configures `PYTHONUTF8=1` and `PYTHONIOENCODING=utf-8` in the environments of child processes (FastAPI backend and Vite frontend), model validation routines, virtual environment detection, and asset compilation.
2. **Raw Byte Preflight Scanner:** Added an automated preflight verification step in `run.py` that reads `backend/.env` and `frontend/.env` strictly as raw bytes, identifies any non-ASCII bytes, and outputs an informative notice with exact line numbers without ever logging or exposing environment keys or values.
3. **Rate Limiter Configuration Isolation:** `backend/app/core/rate_limit.py` was refactored to initialize the `slowapi` Limiter without triggering filesystem `.env` lookups via Starlette's un-encoded `Config` reader, eliminating vulnerability to Windows host character map decodings (`cp1252`) while preserving identical default rate limits (`200/minute`) and route decorators.
4. **Environment Template Sanitization:** Comment blocks in `backend/.env.example` and `frontend/.env.example` were sanitized to strictly standard ASCII characters, preventing accidental copy-paste introduction of multi-byte glyphs into environment files. Real `.env` secret files were never modified or exposed.
5. **Encoding Regression Test:** Added `test_backend_import_without_pythonutf8_with_non_ascii_env` to `backend/tests/test_launcher.py`, verifying that the backend application imports cleanly in a subprocess with `PYTHONUTF8` completely removed and a working-directory `.env` file containing non-ASCII bytes.
6. **Three-Run Verification Without PYTHONUTF8:** `python run.py` was executed three consecutive times from environments with `PYTHONUTF8` stripped, confirming that all three cold starts reached the ready state.
