## 1. Executive Summary

Checkpoint S06 delivers enterprise bulk historical project ingestion and Empirical Bayes productivity calibration for organizations adopting PredictIQ v2. By providing historical completed project data (functional size in IFPUG FP and actual effort in person-hours), organizations dynamically calibrate the global Monotone Power-Law prediction engine toward their empirical team velocity without overfitting small sample sizes ($k$).

Key capabilities delivered:
1. **Empirical Bayes Productivity Shrinkage:** Implemented in `backend/app/services/org_calibration.py`, using shrinkage weight $w = \frac{k}{k + 2.57}$ derived from between-source variance $\tau^2 \approx 0.171$ and within-source residual variance $\sigma^2 \approx 0.441$.
2. **Slope Preservation & Monotonic Scaling:** The global scale elasticity ($b \approx 0.827$) is strictly locked to prevent small-$k$ sample distortions. Quantiles ($P10, P25, P50, P75, P90$) scale proportionally via $\exp(w \cdot \Delta \log a)$, guaranteeing $1.0 \le P10 \le P25 \le P50 \le P75 \le P90$ everywhere.
3. **Robust Bulk Import Endpoint:** Implemented `POST /api/v1/estimates/bulk-import` supporting multipart file uploads (CSV, TSV, semicolon-delimited, UTF-8, UTF-8-BOM, Latin-1) and JSON payloads with row-level validation, error reporting, and automatic calibration computation.
4. **Interactive Calibration Preview:** Implemented `POST /api/v1/estimates/calibration-preview` allowing teams to inspect shrinkage weight, parameter shifts, and before/after MdAPE and PRED(25) gains prior to committing data.
5. **Comprehensive Test Suites:** Authored `backend/tests/test_org_calibration.py` (5 unit tests) and `backend/tests/test_bulk_import.py` (7 API tests), all passing 100%.

## 2. Mathematical Formulation & Empirical Bayes Shrinkage

### 2.1 Model Equations
1. **Global Power Law:**
   $$\ln(E) = \beta_{0, \text{global}} + b_{\text{global}} \cdot \ln(S)$$
   Where $\beta_{0, \text{global}} = 3.1880$ ($a_{\text{global}} \approx 24.24$) and $b_{\text{global}} = 0.8270$.

2. **Organization Productivity Residual:**
   For an organization providing $k$ completed historical projects with size $S_i$ and effort $Y_i$:
   $$r_i = \ln(Y_i) - (\beta_{0, \text{global}} + b_{\text{global}} \cdot \ln(S_i))$$
   $$\Delta \log a_{\text{org}} = \frac{1}{k} \sum_{i=1}^k r_i$$

3. **Empirical Bayes Weight ($w$):**
   $$w = \frac{k}{k + \frac{\sigma^2}{\tau^2}} = \frac{k}{k + 2.57}$$
   - When $k = 0$: $w = 0.0$ (pure global model).
   - When $k = 3$: $w = 0.538$ (53.8% weight on organization actuals).
   - When $k = 5$: $w = 0.660$ (66.0% weight on organization actuals).
   - When $k = 10$: $w = 0.795$ (79.5% weight on organization actuals).
   - As $k \to \infty$: $w \to 1.0$ (fully localized model).

4. **Calibrated Intercept and Exponent:**
   $$\beta_{0, \text{cal}} = \beta_{0, \text{global}} + w \cdot \Delta \log a_{\text{org}}$$
   $$a_{\text{cal}} = \exp(\beta_{0, \text{cal}})$$
   $$b_{\text{cal}} = b_{\text{global}} \quad (\text{strictly preserved})$$

5. **Monotonic Quantile Scaling:**
   $$\text{ratio} = \frac{a_{\text{cal}}}{a_{\text{global}}} = \exp(w \cdot \Delta \log a_{\text{org}})$$
   $$P_{q, \text{cal}} = P_{q, \text{global}} \cdot \text{ratio}$$

## 3. API Endpoints & Schemas

### 3.1 Schemas (`backend/app/schemas/bulk_import.py`)
- `BulkProjectItem`: Individual project data with `project_name`, `size_fp` ($>0$), `actual_hours` ($>0$), optional `start_date`, `completion_date`, `tech_stack`, `industry`, `notes`.
- `BulkImportRequest`: JSON payload carrying list of projects, `consent_to_calibrate` flag, and optional `workspace_id`.
- `BulkImportResponse`: Summary of imported rows, skipped rows, validation errors, and `calibration_preview`.
- `CalibrationPreviewRequest`: Payload containing actuals and optional reference project sizes.
- `CalibrationPreviewResponse`: Detailed breakdown of $k$, shrinkage factor $w$, $a_{\text{global}}$, $a_{\text{calibrated}}$, $b$, multiplier ratio, before/after MdAPE and PRED(25), and calibrated quantiles.

### 3.2 Endpoints in `backend/app/api/v1/estimates.py`
- `POST /api/v1/estimates/bulk-import`:
  - Accepts `application/json` or `multipart/form-data`.
  - Automatically identifies CSV, TSV, or semicolon delimiters.
  - Automatically handles UTF-8, UTF-8-BOM, and Latin-1 byte encodings.
  - Collects row errors and continues importing valid records.
  - Enforces non-negative values and finite numeric ranges.
- `POST /api/v1/estimates/calibration-preview`:
  - Computes instantaneous calibration metrics on provided actuals without saving.
