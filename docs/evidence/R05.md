## 2. Methodology & Statistical Formulation

### Global Hierarchical Model
Let $y_{ij} = \ln(\text{Effort}_{ij})$ and $x_{ij} = \ln(\text{Size}_{ij})$ for project $i$ in organization $j$:
$$y_{ij} = \alpha_j + \beta x_{ij} + \epsilon_{ij}, \quad \epsilon_{ij} \sim \mathcal{N}(0, \sigma^2)$$
$$\alpha_j \sim \mathcal{N}(\alpha_0, \tau^2)$$

Where:
- $\alpha_0, \beta$: Global population marginal elasticity parameters ($b = 0.827$).
- $\tau^2$: Between-organization productivity variance across industry domains ($\tau^2 \approx 0.187$).
- $\sigma^2$: Within-organization project residual variance ($\sigma^2 \approx 0.529$).
- Variance ratio $\sigma^2 / \tau^2 \approx 2.83$.

### Conjugate Normal Shrinkage Estimator
When an organization supplies $k$ delivered actual projects with observed residuals against the global baseline $r_{ij} = \ln(\text{Effort}_{ij}) - \hat{y}_{\text{global}}(x_{ij})$, the sample mean residual is:
$$\bar{r}_j = \frac{1}{k} \sum_{i=1}^k r_{ij}$$

The optimal shrinkage weight $w_k \in [0, 1)$ balancing prior vs observed evidence is:
$$w_k = \frac{\tau^2}{\tau^2 + \sigma^2 / k} = \frac{k}{k + (\sigma^2 / \tau^2)} = \frac{k}{k + 2.83}$$

The organization calibration multiplier $\gamma_{\text{org}}$ applied to all effort quantiles ($P_{10}, P_{50}, P_{90}$) is:
$$\gamma_{\text{org}} = \exp\left(w_k \cdot \bar{r}_j\right)$$

Safety Guardrail: Multiplier is clipped to $[0.33, 3.0]$ to prevent over-fitting on noisy or mis-scoped projects.

## 3. Experimental Results Across 6 LOSO Folds

Experiment script: `backend/ml/eval/run_r05_eb_experiment.py` (50 Monte Carlo trials per fold per $k$).  
Raw data artifact: `docs/evidence/r05_eb_results.json`.

| Actuals Count ($k$) | Shrinkage Weight ($w_k$) | Macro MdAPE (%) | Macro PRED25 (%) | Relative MdAPE Gain | Threshold ($\ge 10\%$) |
|---|---|---|---|---|---|
| **$k = 0$ (Prior Baseline)** | $0.000$ | $56.14\%$ | $19.60\%$ | $0.00\%$ (Ref) | Baseline |
| **$k = 3$** | $0.515$ | $49.46\%$ | $24.14\%$ | **$+11.89\%$** | **PASS** |
| **$k = 5$** | $0.639$ | $47.80\%$ | $25.83\%$ | **$+14.85\%$** | **PASS** |
| **$k = 10$** | $0.779$ | $45.18\%$ | $28.30\%$ | **$+19.52\%$** | **PASS** |
| **$k = 20$** | $0.876$ | $43.37\%$ | $29.89\%$ | **$+22.76\%$** | Monotonic gain |

### Key Findings
1. **Immediate Impact:** Even with as few as 3 actual projects, the model captures organization-level development velocity (e.g. aerospace compliance vs rapid web development), driving an immediate $11.89\%$ relative error reduction.
2. **Smooth Asymptotic Convergence:** As $k$ increases, shrinkage weight smoothly increases from $0.515$ to $0.876$, preventing wild swings while absorbing organization identity.
3. **Monotonic Quantile Invariance:** Because $\gamma_{\text{org}} > 0$, scaling is strictly rank-preserving, guaranteeing $1.0 \le P_{10} \le P_{50} \le P_{90}$.

## 4. Serving & Production Implementation

1. **`backend/app/services/ml_service.py`**:
   - Accepts optional `org_actuals: list[dict[str, float]]`.
   - Computes empirical Bayes shrinkage weight $w_k = k / (k + 2.83)$ and scale factor $\gamma_{\text{org}}$.
   - Exposes calibration metadata in prediction response (`applied`, `k_actuals`, `shrinkage_weight`, `multiplier`).
2. **`backend/app/services/estimate_service.py`**:
   - Automatically queries up to 20 historical actuals from `estimate_actuals` where `consent_for_training = true` and `created_by_user_id = user_id`.
   - Injects actuals into the estimation pipeline seamlessly.
3. **`backend/app/models/estimate.py`**:
   - Added `org_calibration: Optional[dict[str, Any]] = None` to `EstimateOutputs`.
