# Checkpoint R08 Evidence: Likely Band (P25–P75) Alongside Plausible Range (P10–P90)

## 1. Executive Summary
- **Objective:** Provide a two-tier calibrated uncertainty interface with both:
  - **Outer Plausible Range:** 80% coverage interval ($P_{10} \le E \le P_{90}$).
  - **Inner Likely Band:** 50% coverage interval ($P_{25} \le E \le P_{75}$).
- **Mathematical Non-Crossing Invariant:**
  For any input $x$, interval estimates strictly guarantee:
  $$1.0 \le P_{10} \le P_{25} \le P_{50} \le P_{75} \le P_{90}$$
- **Status:** **PASS**

---

## 2. Conformal Calibration Offsets
Trained and calibrated on harmonized `projects_v2.csv` ($N = 915$) with 80/20 train/calibration split (`random_state=42`):

| Strata (Mondrian Bucket) | 80% Conformal Offset ($q_{80}$, P10–P90) | 50% Conformal Offset ($q_{50}$, P25–P75) |
| :--- | :---: | :---: |
| **Small (< 150 FP)** | 1.1481 | 0.6073 |
| **Medium (150 – 750 FP)** | 0.9561 | 0.5999 |
| **Large (> 750 FP)** | 1.1864 | 0.6565 |
| **Global Fallback** | 1.0053 | 0.6004 |

Because $q_{50} < q_{80}$ across every bucket, the inner likely band is strictly narrower than the outer plausible range, preserving finite-sample coverage and non-crossing monotonicity.

## 3. End-to-End Implementation
1. **Calibrator (`backend/ml/calibration/conformal.py`):**
   - Calibrates both 80% and 50% critical thresholds (`global_quantile_`, `global_quantile_50_`, `bucket_quantiles_`, `bucket_quantiles_50_`).
   - `predict_quantiles` returns all 5 quantiles (`p10`, `p25`, `p50`, `p75`, `p90`) with strictly enforced monotonic floors.
2. **Serving Engine (`backend/app/services/ml_service.py`):**
   - Propagates functional size uncertainty to both inner 50% band and outer 80% interval in log space.
   - Applies Empirical-Bayes shrinkage ($\gamma_{\text{org}}$) to all quantiles simultaneously.
   - Exposes `effort_hours: {p10, p25, p50, p75, p90}`, `person_months: {p10, p25, p50, p75, p90}`, `effort_hours_p25`, and `effort_hours_p75`.
3. **API Contracts (`docs/contracts/api_estimate_v2.json`, `backend/app/models/estimate.py`):**
   - Added optional `p25` and `p75` properties to `effort_hours`, `person_months`, and `cost`.
   - Added `effort_p25_hours`, `effort_p75_hours`, `cost_p25_usd`, `cost_p75_usd` to `EstimateOutputs`.
4. **Frontend Visualization (`frontend/src/components/shared/ConfidenceInterval.tsx` & `ResultsPage.tsx`):**
   - Visual track nests the highlighted 50% Likely Band (`p25` to `p75`) inside the 80% Plausible Range (`p10` to `p90`).
   - Summary statistics display both intervals with person-month equivalences (152 hrs/PM).
