## 1. Objectives & Compliance
- **Drop Fabricated Feature Vectors:** Completely eliminated `_build_feature_vector()` in `backend/app/services/ml_service.py` which artificially constructed `T01-T15`, `Transactions`, `Entities`, `PointsNonAdjust`, `Adjustment`, `TeamExp`, and `ManagerExp`.
- **Verified Production Bundle Serving:** Connected `ml_service` directly to `load_production_model()` from `backend.ml.artifacts.loader`.
- **Honest Input Contract:** Only permits legitimate project dimensions: `size_fp` (required, > 0), `duration_months` (optional), and `team_size` (optional).
- **Calibrated Prediction Intervals:** Returns conformal quantile estimates (`p10`, `p50`, `p90`) guaranteeing monotonicity: `1.0 <= p10 <= p50 <= p90`.
- **Empirical Unit Conversion:** Standard 152 productive hours per person-month conversion for `person_months` (`p10`, `p50`, `p90`).
- **Data Quality Tiers & OOD Flags:** Emits transparent Data Quality Tiers (`A`, `B`, `C`) and explicit out-of-distribution flags based on empirical dataset boundaries [4.0, 4100.0] FP.

## 2. Implementation Details

### `backend/app/services/ml_service.py`
- Implemented `MLService` with lazy, verified artifact loading via `ProductionModelBundle`.
- Standard conversion factor: `HOURS_PER_PERSON_MONTH = 152.0`.
- Implemented OOD boundary detection:
  - `size_fp_below_training_min` (< 4.0 FP)
  - `size_fp_exceeds_training_max` (> 4100.0 FP)
  - `duration_months_extreme` (< 1.0 or > 60.0 months)
  - `team_size_extreme` (< 1 or > 50 engineers)
- Assigns Quality Tier:
  - `Tier A`: User-entered `size_fp` within empirical dataset range with zero OOD flags.
  - `Tier B`: NLP-extracted `size_fp` with verified document structure within normal domain.
  - `Tier C`: Any OOD flag triggered or low document confidence.

### Verification Suite (`backend/tests/test_ml_service.py`)
12 tests created covering all contract aspects:
1. `test_ml_service_is_ready`: Verified model bundle is loaded and operational.
2. `test_model_info_conforms_to_contract`: Verified health check metadata and parameter reporting.
3. `test_valid_prediction_structure`: Verified `p10 <= p50 <= p90` effort and person-month bounds.

8. `test_ood_detection_small_size`: Verified size < 4.0 triggers flag and Tier C.
