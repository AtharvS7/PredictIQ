## 1. Objectives & Scope

Checkpoint CP21 elevates the PredictIQ frontend design system, typography, spacing, and component primitives to startup-grade quality:
1. **Modern High-Contrast Dark/Light Palette:** WCAG AAA/AA compliant color tokens with deep obsidian dark mode (`#090D16` / `#111827`) and crisp slate light mode (`#F8FAFC` / `#FFFFFF`).
2. **Typography Scale & Optical Sizing:** Clean font scale from `text-2xs` (11px) to `text-4xl` (36px), paired with JetBrains Mono for financial/effort metrics and model hashes.
3. **Refined Card Containers:** Versatile card primitives (`default`, `elevated`, `interactive`, `accent`, `glass`, `subtle`) with header, title, description, content, and footer subcomponents.
4. **Data Quality & Model Badges:** Semantic badge primitives for Data Quality Tiers (`Tier A` Certified Benchmark, `Tier B` Validated Standard, `Tier C` Heuristic), Model Versioning (with git/model SHA and source counts), and Uncertainty intervals (`80% CI`, conformal coverage).
5. **Confidence Interval Primitives:** `ConfidenceRangeBar` and `ConfidenceIntervalCard` displaying p10 (best-case), p50 (calibrated median), and p90 (conservative ceiling) with visual horizontal uncertainty track, median pip marker, spread ratios, and accessible ARIA attributes.
6. **Strict Verification:** Clean typecheck, 100% passing test suite across all 19 test files (103 tests), and successful production build.

## 2. Design System Tokens (`frontend/src/index.css`)

### 2.1 Typography Scale
- `--font-sans`: `'Inter', system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- `--font-mono`: `'JetBrains Mono', 'Fira Code', 'SF Mono', Consolas, monospace`
- Font Sizes & Line Heights:
  - `text-2xs`: `0.6875rem` (11px) / `lh-2xs: 1rem` (uppercase overlines, metadata chips)
  - `text-xs`: `0.75rem` (12px) / `lh-xs: 1rem` (captions, subtexts)
  - `text-sm`: `0.875rem` (14px) / `lh-sm: 1.25rem` (body-sm, inputs, buttons)
  - `text-base`: `1rem` (16px) / `lh-base: 1.5rem` (body copy)
  - `text-lg`: `1.125rem` (18px) / `lh-lg: 1.75rem` (card titles, lead copy)
  - `text-xl`: `1.25rem` (20px) / `lh-xl: 1.75rem` (h3 headings, medium metrics)
  - `text-2xl`: `1.5rem` (24px) / `lh-2xl: 2rem` (h2 page section headings)
  - `text-3xl`: `1.875rem` (30px) / `lh-3xl: 2.25rem` (h1 page titles)
  - `text-4xl`: `2.25rem` (36px) / `lh-4xl: 2.5rem` (display headings)

## 3. Component Primitives Created

### 3.1 `Card.tsx` (`frontend/src/components/shared/Card.tsx`)
- Modular container system: `<Card>`, `<CardHeader>`, `<CardTitle>`, `<CardDescription>`, `<CardContent>`, `<CardFooter>`.
- Variants: `default`, `elevated`, `interactive` (hover translate + shadow glow), `accent` (brand top border), `glass`, `subtle`.
- Configurable padding: `none`, `sm`, `md`, `lg`.

### 3.2 `Badge.tsx` (`frontend/src/components/shared/Badge.tsx`)
- Core `<Badge>` supporting `primary`, `success`, `warning`, `danger`, `info`, `neutral`, `default` with pill/outline/dot options.
- `<DataQualityBadge>`: Visual indicator for Tiers A, B, and C with semantic icons (`ShieldCheck`, `Database`, `AlertCircle`) and glowing outline ring.
- `<ModelVersionBadge>`: Displays model version string (e.g. `2.0.0-rc.1`), git/model SHA chip (`#0bea59f`), and historical dataset source count (`4 sources`).
- `<UncertaintyBadge>`: Calibrated statistical indicator (`80% CI (p10–p90) • 90% Conformal`).

### 3.3 `ConfidenceInterval.tsx` (`frontend/src/components/shared/ConfidenceInterval.tsx`)
- `<ConfidenceRangeBar>`: Visual horizontal range visualization:
  - Background track with safety bounds
  - Calibrated confidence band (p10 to p90) with subtle gradient shading
  - p10 tick (emerald), p50 pip marker (blue glow diamond/pill), p90 tick (amber)
  - Numerical readout grid with tabular numbers and delta percentage from median
  - Uncertainty spread ratio badge (`p90/p10 = 2.5x`)
  - Deterministic locale formatting (`en-US`) for currency, hours, weeks, and function points.
- `<ConfidenceIntervalCard>`: Self-contained card layout combining Title, DataQualityBadge, UncertaintyBadge, and RangeBar.

### 3.4 `Typography.tsx` (`frontend/src/components/shared/Typography.tsx`)
- `<Heading>`: Responsive h1-h6 headings with optical letter-spacing and line-height.
- `<Text>`: Text elements supporting `body`, `body-sm`, `body-lg`, `caption`, `overline`, `muted`, and `mono`.
- `<MetricValue>`: High-contrast metric display with tabular numbers, unit suffix, subtext, and trend badges (`up`, `down`, `neutral`).
- `<CodeChip>`: Monospace code token badge for hashes, quantiles, and parameters.
